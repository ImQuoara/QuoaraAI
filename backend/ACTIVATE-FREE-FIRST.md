# Activation sequence (no new paid services required)

1. Confirm Supabase owner account user ID and set `QUOARAAI_OWNER_USER_ID`.
2. Create free Cloudflare account + Workers AI token.
3. Create free Tavily account + API key.
4. Apply the owner alpha migration.
5. Set environment variables.
6. Deploy to an approved free host.
7. Sign in as owner and install the PWA on phone.

## Important
- No paid fallback is enabled.
- If free quotas are exhausted, requests fail closed.
- QuoaraAi may not switch to a paid provider without a new owner decision.
