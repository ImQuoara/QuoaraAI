# QuoaraAi next foundation roadmap

1. Android Keystore challenge signing for sensitive approvals.
2. Native authentication/session layer replacing WebView login dependency.
3. Native Chat screen and streaming transport.
4. Native Research screen with source cards.
5. Native Create screen with Android Photo Picker and share sheet.
6. Media vault with provenance, provider, model, prompt, approval, cost, and licensing metadata.
7. Model Arena for evidence-based routing comparisons.
8. QuoaraAi Lab for draft-only upgrade candidates and benchmark results.
9. VideoProvider implementation only after provider pricing/content/commercial terms are reviewed.
10. Read-only YouTube/Meta integrations first; publishing remains exact-action approval gated.
