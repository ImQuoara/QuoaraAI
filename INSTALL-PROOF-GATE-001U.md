# QuoaraAi 001U — Phone Installation Proof Gate

Before installation is called verified:
- source baseline must be `001U`;
- package must be `com.imquoara.quoaraai`;
- version must be `0.4.8-alpha` / `versionCode 12`;
- GitHub Android CI must complete successfully;
- APK-PROOF.txt must be non-empty and contain APK SHA-256, aapt badging, and apksigner verification;
- installed app must visibly report matching package/version/baseline/backend origin;
- physical-phone login, WebView boundary, device signing, and approval paths remain runtime tests.
